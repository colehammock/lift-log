# Lift Log

A simple iPhone workout logger built on Jeff Nippard's Fundamentals Hypertrophy Program.

- **Today**: the next workout in your program, chosen so you rest the muscles you trained last time. Missed days don't matter; it just picks up where you left off.
- **Supersets**: accessories that share equipment (dumbbells or cables) are paired so you stay in one spot. The big lifts stay as straight sets with warm-ups.
- **Progressive overload**: each exercise suggests today's weight from your last session. It goes up when you hit every rep.
- **Form**: the program's cue for each exercise, a demo video link, and the program's approved swaps.
- **Stats**: progress per exercise, sets per week, and sets per muscle against the 10–15 set target.

Plain HTML/CSS/JS with no build step, served by GitHub Pages. Workout data stays on the phone (localStorage). Use Settings → Backup to save a copy.
